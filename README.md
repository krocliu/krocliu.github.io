# 淘宝茶叶市场月度排行榜

静态 React 数据看板，用于展示淘宝商品的月度 Top 300 与跨月趋势；界面可独立切换“茶叶”“茶叶包装”“茶叶罐及礼盒”三个类目。

当前三个类目均已导入 2025 年 7 月至 2026 年 7 月共 13 个月的数据。该来源提供的是“支付买家数”和“访客数”区间，而非精确销量、价格或销售额；看板会保留原始区间，并仅使用区间中位值进行趋势估算。

## 快速开始

在 Windows 中可直接双击项目根目录的 `启动茶叶排行榜.bat`。

或在终端执行：

```bash
npm install
npm run demo-data
npm run dev
```

浏览器访问终端显示的本地地址即可预览演示看板。

## 导入真实数据

1. 将茶叶文件放入 `data/source/`；茶叶包装文件放入 `data/source/packaging/`；茶叶罐及礼盒文件放入 `data/source/containers/`。每个目录均支持每月一个的 `.csv`、`.xlsx` 或 `.xls` 文件。
2. 通用文件需要包含：商品 ID（或商品链接）、商品名称、店铺名称、价格、销量、销售额；月份可放在列中，或写入文件名（例如 `2026-08.csv`）。当前茶行业格式也支持“商品、店铺、支付买家数、访客数、商品图片URL、商品地址URL”。
3. 执行：

```bash
npm run process-data
npm run dev
```

处理完成后会生成 `public/data/rankings.json` 和 `data/import-report.json`。若存在字段缺失、无效数值或无法识别月份，脚本会停止并在报告中列出错误；同月完全重复的商品会保留首次出现记录并写入提示。

## 发布

```bash
npm run build
```

将生成的 `dist/` 目录部署到任意静态网站托管服务即可。
